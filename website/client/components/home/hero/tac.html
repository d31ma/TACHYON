Tachyon

Build the frontend and the backend of your app in one project.

Write standard HTML. Tac, the frontend part, shows it in the browser. Tac also builds the same page as a desktop or mobile app for macOS, Windows, Linux, Android and iOS. Yon, the backend part, runs REST controllers in many languages. A controller is a class that answers HTTP requests. Annotations on the class and its methods give its URL paths.
