Where no host links it, a Rust, C#, Swift or Kotlin service is
WebAssembly, and a Go service is WebAssembly everywhere: the web
platform is out of reach, and the service is state and logic over
what its tag passes (ADR 0035, ADR 0037, ADR 0045, ADR 0078,
ADR 0082).

companion.invoke carries a service instance's asynchronous member
requests to its selected native service, named by instance: basket.
The host checks the local origin, main frame and canonical route before
dispatch. Window controls are a separate, manifest-granted surface.
Native service code is trusted application code with the host
process's OS permissions, not a sandbox or an unrestricted reflection
bridge from the page.
