Android

name, short_name
  honored: app_name in strings.xml

start_url
  honored: the page the app opens first

icons
  adapted: icons: the Android app copies the largest raster icon into mipmap-xxxhdpi without resizing it.

theme_color
  adapted: theme_color is written into each page head, but the Android status bar does not use it yet (WIN5).

background_color
  adapted: background_color is not applied to the Android app yet.

display
  adapted: display is not applied yet. The Android app keeps the system bars (WIN5).

orientation
  adapted: orientation is not applied yet. The Android app turns with the device (WIN5).

tachyon (top-level)
  refused with TY1601: The top-level tachyon member is gone. Move its values into tac (ADR 0052).

other standard manifest members
  adapted: The Android app does not use the standard members scope, id, description, lang, shortcuts, share_target, file_handlers, protocol_handlers or display_override. They are published only for browsers.

tac.application
  honored: the app's identity

tac.application.id
  adapted: tac.application.id becomes the Android applicationId after characters that Android refuses are replaced.

tac.application.version
  honored: versionName

tac.application.build
  honored: versionCode; a build above 2100000000 stops the build (TY1601)

tac.application.window.width, height
  not applicable: tac.application.window width and height have no meaning on Android: the system sizes the app.

tac.application.window.minWidth, minHeight
  not applicable: tac.application.window minWidth and minHeight have no meaning on Android: the system sizes the app.

tac.application.window.controls
  adapted: tac.application.window.controls on Android act on the activity: close finishes it, minimize moves it to the back, and fullscreen hides the system bars.

tac.application.window.titleBar
  adapted: tac.application.window.titleBar "integrated" is built only for macOS. The Android app keeps the standard status bar (ADR 0098, WIN5).

tac.application.window.titleBarButtonInset
  not applicable: tac.application.window.titleBarButtonInset has no meaning on Android: the app has no window buttons.

tac.application.menus
  refused with TY1601: Android apps have no menu bar. Put links or buttons in the page instead (D1).

tac.application.rust
  adapted: tac.application.rust crates are not used on Android: Rust services run as WebAssembly in the page there (D1).

tac.application.rust.executables
  refused with TY1601: An Android app may not start other programs. Do the work in a service, or remove tac.application.rust.executables for this target.

tac.origin
  not applicable: tac.origin is for search engines and the web server. The Android app bundle still holds sitemap.xml and robots.txt, but nothing reads them there.

tac.sitemap
  not applicable: tac.sitemap adds entries to sitemap.xml for search engines. The Android app bundle holds the file, but nothing reads it there.

tac.scripts
  honored: the same page head as the web build

tac.blockingScripts
  honored: the same page head as the web build

tac.styles
  honored: the same page head as the web build

tac.styleSources
  honored: the same checked files, bundled into the app

tac.scriptSources
  honored: the same checked files, bundled into the app

tac.cache
  adapted: tac.cache is not used in the Android app: the bundle is local and there is no service worker. The rules will apply to Yon reads after NET6.

tac.metadata
  adapted: tac.metadata tags are written into each page, but search-engine and sharing tags do nothing inside the Android app.

tac.browserApis
  honored: the same grant list in the page

tac.browserApis clipboard
  adapted: clipboard in the Android app uses the web view's navigator.clipboard, and no host test checks it yet (BA2).

tac.browserApis share
  adapted: share does not work in the Android app yet: its web view has no navigator.share (BA2).

tac.browserApis notifications
  adapted: notifications do not work in the Android app yet: its web view has no Notification API (BA2).

tac.browserApis geolocation
  adapted: geolocation does not work in the Android app yet: the host turns it off in the web view (BA2).

tac.browserApis preferenceStrings
  honored: the web view's localStorage, kept on disk

tac.nativeCapabilities
  adapted: tac.nativeCapabilities filePicker is not built for Android yet. FilePicker answers unsupported (FP2).

tac.elements
  adapted: tac.elements are bundled into the Android app for its own pages only. Other sites cannot load them from the app.

tac.python
  honored: Pyodide in the web view, checked in code only (ADR 0093)

tac.budgets
  not applicable: tac.budgets is checked only by web release builds. The Android app loads its bundle from disk, so route sizes are not measured (ADR 0074).

tac.outgoing
  adapted: The Android app lets page requests reach the hosts in tac.outgoing.hosts over https only: the platform refuses cleartext http and ws. It asks for the INTERNET permission only when the list names a host.

tac.go
  honored: the same Go WebAssembly build in the web view

tac.dotnet
  honored: the same WebAssembly build in the web view

tac.accessibility
  honored: the same build check

tac.cohesion
  honored: the same build check

tac.duplication
  honored: the same build check

tac.dependencies
  honored: the same build check

tac.names
  honored: the same build check

tac.signatures
  honored: the same build check

tac.constants
  honored: the same build check

tac.implicitmembers
  honored: the same build check

tac.visibility
  honored: the same build check

tac.types
  honored: the same build check

tac.tests
  honored: the same build check; ty test runs on the build machine

tac.simplify
  honored: the same build check

application lifetime services
  refused with TY1406: Application lifetime services must be Rust, and Rust is not linked on Android yet. Use a page or singleton service (D1).

standard menu bar without declared items
  not applicable: An Android app has no menu bar (MN1 adapts declared items).

Edit menu
  not applicable: The system text toolbar handles text on Android.

Window menu
  not applicable: The system owns the Android window.

menu shortcuts with control
  refused with TY1601: Android apps have no menu bar, so menus are refused until MN1.

window drag regions (data-tac-drag-region)
  not applicable: An Android app has no window to move.

external links
  honored: http, https and mailto links open in the default browser or mail app (ACTION_VIEW)

deep links
  adapted: The Android app cannot be opened at a route from a link yet (LK2).

background and foreground signal
  adapted: The Android host sends services no background or foreground signal. Only the web view's own page visibility events can reach them, and no host test checks those (LC1).

stored data (IndexedDB, Cache API, LocalState)
  honored: kept on disk by the web view

Content-Security-Policy
  honored: the native host policy, which also allows the host's bridge script by its hash

reaching Yon
  adapted: The Android app cannot reach a Yon server: its pages load from a local origin, and only the hosts in tac.outgoing.hosts are reachable (NET0, NET2).

natively linked service languages
  honored: Kotlin services are linked into the app; other languages run in the page

release packaging
  adapted: The Android build is a debug APK. Release APK and AAB builds wait on PKG3.
