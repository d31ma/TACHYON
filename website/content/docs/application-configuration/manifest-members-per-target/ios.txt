iOS

name, short_name
  honored: CFBundleName and CFBundleDisplayName

start_url
  honored: the page the app opens first

icons
  honored: the largest raster icon is resized to the app icon set; staging the app on another system skips the icon and prints a note

theme_color
  adapted: theme_color fills the area behind the iOS status bar and picks dark or light status bar text by contrast, when it is written as #rgb or #rrggbb. With titleBar "integrated" the page draws there instead and theme_color only picks the text color. Other color forms keep the system background.

background_color
  adapted: background_color colors the iOS launch screen and the web view behind the page, when it is written as #rgb or #rrggbb. Other color forms keep the system background.

display
  adapted: display "fullscreen" hides the iOS status bar from launch and lets the home indicator fade. The other values keep the status bar.

orientation
  adapted: orientation sets the iOS supported interface orientations: portrait and landscape allow both turns of the device, the -primary and -secondary values one, natural means portrait, and any (or no value) allows all four. iPhones without a Home button never turn upside down. A locked orientation also asks iPadOS for full screen, because iPad windows that share the screen turn freely.

tachyon (top-level)
  refused with TY1601: The top-level tachyon member is gone. Move its values into tac (ADR 0052).

other standard manifest members
  adapted: The iOS app does not use the standard members scope, id, description, lang, shortcuts, share_target, file_handlers, protocol_handlers or display_override. They are published only for browsers.

tac.application
  honored: the app's identity and menus

tac.application.id
  honored: CFBundleIdentifier

tac.application.version
  honored: CFBundleShortVersionString; a version that is not one to three numbers stops the build (TY1601)

tac.application.build
  honored: CFBundleVersion

tac.application.minimumSystem
  honored: MinimumOSVersion and the swiftc target (17.4 unless set, the first with CSS @scope for component styles; 18.2 with a Dart, Kotlin or Java web service; ADR 0108); a value below that floor stops the build (TY1601). Kotlin, Dart and Java apps built at 18.2 opened on the iOS 26.5 simulator (RM2)

tac.application.links
  adapted: tac.application.links: the iOS app claims the listed schemes in Info.plist and opens their links at their route, or at start_url when the route is unknown. Universal links to the listed hosts need TAC_APPLE_TEAM_ID and a --device or --release build, whose profile has the Associated Domains capability; no signed build has opened one on a device yet. A simulator build opens only the custom schemes.

tac.application.window.width, height
  not applicable: tac.application.window width and height have no meaning on iOS: the system sizes the app.

tac.application.window.minWidth, minHeight
  not applicable: tac.application.window minWidth and minHeight have no meaning on iOS: the system sizes the app.

tac.application.window.controls
  adapted: tac.application.window.controls: iOS apps have no window controls; the system owns the window. Only title applies there, as the scene title, for calls from the page and from linked Swift services. granted() answers false for the other controls.

tac.application.window.titleBar
  adapted: tac.application.window.titleBar "integrated" lets the iOS page draw edge to edge, under the status bar. --tac-titlebar-height is the top safe-area inset, and the leading and trailing insets are the side safe-area insets. There are no window buttons and no drag regions (ADR 0098).

tac.application.window.titleBarButtonInset
  not applicable: tac.application.window.titleBarButtonInset has no meaning on iOS: the app has no window buttons.

tac.application.menus
  adapted: iPad menu bar / iPhone shortcuts: route items join the File, View and Help menus of the iPad menu bar, and on iPhone only items with a shortcut are reachable, from a hardware keyboard. Action items call a method of an application service and are enabled only while the page listens for their event (MN1b). iPadOS keeps some Command shortcuts, such as Command-G, for its own menus, so such an item never fires from the keyboard on iPad.

tac.application.tray
  refused with TY1601: iOS has no status area. Put these controls in the page instead (ADR 0107).

tac.application.tray.template
  not applicable: tac.application.tray.template has no meaning on iOS, which refuses tac.application.tray.

tac.application.tray.closeHidesWindow
  not applicable: tac.application.tray.closeHidesWindow has no meaning on iOS, which refuses tac.application.tray.

tac.application.tray.dock
  not applicable: tac.application.tray.dock has no meaning on iOS, which refuses tac.application.tray.

tac.application.rust
  honored: vendored crates linked into the app's Rust services, built for aarch64-apple-ios or the simulator; platformDependencies.ios applies only here. A Rust service using a vendored crate answered the page on the iOS 26.5 simulator (RM2)

tac.application.rust.executables
  refused with TY1601: An iOS app may not start other programs. Do the work in a service, or remove tac.application.rust.executables for this target.

tac.origin
  not applicable: tac.origin is for search engines and the web server. The iOS app bundle still holds sitemap.xml and robots.txt, but nothing reads them there.

tac.sitemap
  not applicable: tac.sitemap adds entries to sitemap.xml for search engines. The iOS app bundle holds the file, but nothing reads it there.

tac.cache
  honored: the page applies the rules to Yon reads at tac.yon.origin in its own Cache Storage, which the web view keeps on disk; with Yon stopped, network-first and cache-first reads answered from the kept copy on the iOS 26.5 simulator, also after a relaunch (RM2)

tac.metadata

tac.application.permissions

tac.browserApis
  honored: the same grant list in the page

tac.browserApis clipboard
  honored: UIPasteboard through the host bridge (browserApi.clipboard)

tac.browserApis share
  honored: UIActivityViewController through the host bridge (browserApi.share); a tap on the iOS 26.5 simulator opened the share sheet, and closing it reported a cancelled share (RM2)

tac.browserApis notifications
  honored: UNUserNotificationCenter through the host bridge (browserApi.notifications), also shown while the app is in front; the iOS 26.5 simulator displayed the permission prompt and a banner (RM2)

tac.browserApis geolocation
  honored: CoreLocation through the host bridge (browserApi.geolocation), asking with the reason from tac.application.permissions; the page got the simulated position on the iOS 26.5 simulator (RM2)

tac.browserApis preferenceStrings
  honored: the web view's localStorage, kept on disk; a value was read back after a terminate and relaunch on the iOS 26.5 simulator (RM2)

tac.nativeCapabilities
  honored: filePicker opens the document picker (UIDocumentPickerViewController) for page, Swift and Rust services, and for C# and Kotlin services, which run as WebAssembly on iOS and reach the picker through the page; each chose, read and cancelled on the iOS 26.5 simulator (FP4)

tac.elements
  adapted: tac.elements are bundled into the iOS app for its own pages only. Other sites cannot load them from the app.

tac.python
  honored: Pyodide in the web view (ADR 0093); a Python service answered the page on the iOS 26.5 simulator (RM2)

tac.budgets
  not applicable: tac.budgets is checked only by web release builds. The iOS app loads its bundle from disk, so route sizes are not measured (ADR 0074).

tac.outgoing
  honored: the build checks request hosts and the scheme handler's connect-src allows only them; a page fetch to an undeclared host was refused on the iOS 26.5 simulator (RM2)

tac.yon

application lifetime services
  adapted: Rust services start once when the app launches and serve every page (LT1, iPhone and iPad simulators). Their OnStop runs only from applicationWillTerminate: iOS ends a suspended app without telling it, and on the simulator a SIGTERM ended the app without that call, so do not keep unsaved data only until OnStop.

standard menu bar without declared items
  not applicable: Without declared items, an iOS app keeps the system's own iPad menu bar and adds nothing.

Edit menu
  not applicable: The system edit menu handles text on iOS.

Window menu
  not applicable: The system owns the iOS window.

menu shortcuts with control
  honored: the Control key

page accessibility (roles and names through the system accessibility API)
  honored: the web view's accessibility tree, which VoiceOver reads; on the iOS 26.5 simulator scripts/ios/accessibility-audit-test.mjs read the heading, image, text field, button and link by role and name through XCUITest, and typed into the field, pressed the button and opened the link through it (AX1)

window drag regions (data-tac-drag-region)
  not applicable: An iOS app has no window to move.

external links
  honored: http, https and mailto links open in the default browser or mail app (UIApplication); on the iOS 26.5 simulator http and https opened Safari, mailto went to the system, and links with a user name opened nothing (RM2)

deep links
  honored: with tac.application.links, a link with a listed scheme opens the app at its route, run on the iOS simulator; universal links to listed hosts are described under tac.application.links

system back navigation
  run owed: a swipe from the left edge goes back and a swipe from the right edge goes forward through the web view's history; still to run: scripts/ios/system-back-test.mjs on the iOS simulator

background and foreground signal
  honored: ApplicationStateChanged when the app enters the background and when it returns to the foreground; the page and a linked Swift service heard both on the iOS 26.5 simulator (RM2)

stored data (IndexedDB, Cache API, LocalState)
  honored: kept on disk by the web view; Store rows, LocalState values and Cache API entries were read back after a terminate and relaunch on the iOS 26.5 simulator (RM2)

service worker
  not applicable: The iOS app registers no service worker: its pages load from the app bundle. With tac.yon.origin set, the page applies tac.cache rules to Yon reads itself; without it, tac.cache has no effect in the app.

Content-Security-Policy
  honored: the native host policy; connect-src refused an undeclared host on the iOS 26.5 simulator (RM2)

reaching Yon
  adapted: The iOS app's pages load from tachyon-app://bundle, so same-origin requests reach no Yon. Pages and linked Swift and Rust HTTP clients reach the Yon at tac.yon.origin, run on the iOS simulator over http and https by scripts/native/yon-reach-test.mjs (NET1, LR1). The page holds a linked Rust service's stream and socket clients, and that run reached Yon through them too (LR1). The page holds a linked Swift service's stream and socket clients and delivers their messages to it (LS1); an iOS simulator run of that is still owed (yon-reach-test.mjs with a linked Swift stream and socket).

natively linked service languages
  honored: Rust and Swift services are linked into the app, with Swift chosen when a service has both; other languages run in the page

build architecture (--arch)
  adapted: --arch does not choose the iOS architecture: the simulator app is built for the build machine's architecture, and --device and --release builds are always arm64.

development code signing
  honored: a simulator app is signed ad hoc, and a --device build with the Apple Development certificate that its provisioning profile names

release packaging
  run owed: ty bundle --release builds an .ipa for App Store Connect, signed with the App Store profile that TAC_IOS_PROVISIONING_PROFILE names and its keychain certificate, and --device builds one for a registered iPhone or iPad; the team comes from TAC_APPLE_TEAM_ID. Other builds run in the simulator; still to run: a --release build with an App Store profile and an install on an iOS 17 or later device; a --device build was signed and checked on a Mac, and the App Store Connect upload is outside ty (ADR 0104)

incremental route reuse
  honored: routes are reused from the previous app's web folder; --no-incremental turns this off

byte-identical rebuilds
  honored: the iOS build passes SOURCE_DATE_EPOCH and ZERO_AR_DATE to swiftc and compiles from the source folder; a signed --device or --release .ipa is never byte-identical. a_packaged_ios_app_is_byte_identical_when_built_twice passed on a Mac (RM2)

running without a signed-in desktop session
  honored: the app runs in the iOS simulator without a screen
