macOS

name, short_name
  honored: CFBundleName and CFBundleDisplayName

start_url
  honored: the page the app opens first

icons
  honored: the largest raster icon becomes the .icns file; staging the app on another system skips the icon and prints a note

theme_color
  adapted: theme_color is written into each page head, but the macOS window does not use it yet.

background_color
  adapted: background_color is not applied to the macOS app yet.

display
  adapted: display is not applied yet. The macOS app opens a standard window.

orientation
  not applicable: orientation has no meaning for a macOS window.

tachyon (top-level)
  refused with TY1601: The top-level tachyon member is gone. Move its values into tac (ADR 0052).

other standard manifest members
  adapted: The macOS app does not use the standard members scope, id, description, lang, shortcuts, share_target, file_handlers, protocol_handlers or display_override. They are published only for browsers.

tac.application
  honored: the app's identity, window and menus

tac.application.id
  honored: CFBundleIdentifier

tac.application.version
  honored: CFBundleShortVersionString; a version that is not one to three numbers stops the build (TY1601)

tac.application.build
  honored: CFBundleVersion

tac.application.window.width, height
  honored: the first size of the window

tac.application.window.minWidth, minHeight
  honored: the smallest size of the window

tac.application.window.controls
  honored: close, fullscreen, maximize (zoom), minimize, resize and title

tac.application.window.titleBar
  honored: "integrated" draws the page under the title bar

tac.application.window.titleBarButtonInset
  honored: moves the window buttons of an integrated title bar

tac.application.menus
  honored: items in the File, View and Help menus of the menu bar

tac.application.rust
  honored: vendored crates linked into the app's Rust services

tac.application.rust.executables
  honored: signed helper programs in Contents/MacOS

tac.origin
  not applicable: tac.origin is for search engines and the web server. The macOS app bundle still holds sitemap.xml and robots.txt, but nothing reads them there.

tac.sitemap
  not applicable: tac.sitemap adds entries to sitemap.xml for search engines. The macOS app bundle holds the file, but nothing reads it there.

tac.scripts
  honored: the same page head as the web build

tac.blockingScripts
  honored: the same page head as the web build

tac.styles
  honored: the same page head as the web build

tac.styleSources
  honored: the same checked files, bundled into the app

tac.scriptSources
  honored: the same checked files, bundled into the app

tac.cache
  adapted: tac.cache is not used in the macOS app: the bundle is local and there is no service worker. The rules will apply to Yon reads after NET6.

tac.metadata
  adapted: tac.metadata tags are written into each page, but search-engine and sharing tags do nothing inside the macOS app.

tac.application.permissions
  honored: NSLocationUsageDescription and NSLocationWhenInUseUsageDescription in Info.plist

tac.browserApis
  honored: the same grant list in the page

tac.browserApis clipboard
  adapted: clipboard in the macOS app uses the web view's navigator.clipboard, and no host test checks it yet (BA1).

tac.browserApis share
  adapted: share in the macOS app uses the web view's navigator.share, and no host test checks it yet (BA1).

tac.browserApis notifications
  adapted: notifications do not work in the macOS app yet: its web view has no Notification API (BA1).

tac.browserApis geolocation
  adapted: geolocation in the macOS app uses the web view's navigator.geolocation, with the reason from tac.application.permissions in Info.plist. No host test checks it yet (BA1).

tac.browserApis preferenceStrings
  honored: the web view's localStorage, kept on disk

tac.nativeCapabilities
  honored: filePicker opens the system file panel

tac.elements
  adapted: tac.elements are bundled into the macOS app for its own pages only. Other sites cannot load them from the app.

tac.python
  honored: Pyodide in the web view, checked in code only (ADR 0093)

tac.budgets
  not applicable: tac.budgets is checked only by web release builds. The macOS app loads its bundle from disk, so route sizes are not measured (ADR 0074).

standard menu bar without declared items
  honored: the App, File, Edit and Window menus

  honored: Undo, Redo, Cut, Copy, Paste and Select All

  honored: Minimize, Zoom and Bring All to Front

menu shortcuts with control
  honored: the Control key

page accessibility (roles and names through the system accessibility API)
  honored: the web view's accessibility tree, checked by the macOS gate

window drag regions (data-tac-drag-region)
  honored: dragging a marked element moves the window

external links
  honored: http, https and mailto links open in the default browser or mail app (NSWorkspace)

deep links
  adapted: The macOS app cannot be opened at a route from a link yet (LK2).

background and foreground signal
  adapted: The macOS host sends services no background or foreground signal. Only the web view's own page visibility events can reach them, and no host test checks those (LC1).

stored data (IndexedDB, Cache API, LocalState)
  honored: kept on disk by the web view

Content-Security-Policy
  honored: the native host policy

reaching Yon
  adapted: The macOS app cannot reach a Yon server with same-origin requests: its pages load from a local origin. Requests to an absolute URL go only to the hosts in tac.outgoing.hosts (NET0, NET1).

natively linked service languages
  honored: Rust and Swift services are linked into the app; other languages run in the page

build architecture (--arch)
  honored: --arch x64, arm64 or universal; universal joins an arm64 and an x86_64 build with lipo

release packaging
  adapted: The macOS build is an unsigned .app bundle. Signing, notarization and a .dmg wait on PKG1.
