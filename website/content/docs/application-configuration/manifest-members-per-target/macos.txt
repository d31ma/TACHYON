macOS

name, short_name
  honored: CFBundleName and CFBundleDisplayName

start_url
  honored: the page the app opens first

icons
  honored: the largest raster icon becomes the .icns file; staging the app on another system skips the icon and prints a note

theme_color
  not applied: theme_color is written into each page head, but the macOS window does not use it yet (WIN7).

background_color
  not applied: background_color is not applied to the macOS app yet (WIN7).

display
  not applied: display is not applied yet. The macOS app opens a standard window (WIN7).

orientation
  not applicable: orientation has no meaning for a macOS window.

tachyon (top-level)
  refused with TY1601: The top-level tachyon member is gone. Move its values into tac (ADR 0052).

other standard manifest members
  adapted: The macOS app does not use the standard members scope, id, description, lang, shortcuts, share_target, file_handlers, protocol_handlers or display_override. They are published only for browsers.

tac.application
  honored: the app's identity, window and menus

tac.application.id
  honored: CFBundleIdentifier

tac.application.version
  honored: CFBundleShortVersionString; a version that is not one to three numbers stops the build (TY1601)

tac.application.build
  honored: CFBundleVersion

tac.application.minimumSystem
  honored: LSMinimumSystemVersion and the swiftc target (13.0 unless set; 15.2 with a Dart, Kotlin or Java web service); a value below that floor stops the build (TY1601)

tac.application.links
  adapted: tac.application.links: the macOS app claims the listed schemes in Info.plist and opens their links at their route, or at start_url when the route is unknown. Links to the listed hosts stay in the browser, because the unsigned app has no associated domains (PKG1).

tac.application.window.width, height
  honored: the first size of the window

tac.application.window.minWidth, minHeight
  honored: the smallest size of the window

tac.application.window.controls
  run owed: close, fullscreen, maximize (zoom), minimize, resize and title; still to run: a granted control from a page or service on a Mac; the GUI checks run only the refused path

tac.application.window.titleBar
  honored: "integrated" draws the page under the title bar

tac.application.window.titleBarButtonInset
  honored: moves the window buttons of an integrated title bar

tac.application.menus
  honored: items in the File, View and Help menus of the menu bar

tac.application.tray
  honored: a status item in the menu bar with Open, the declared items and Quit (ADR 0107)

tac.application.tray.template
  honored: a template image that the menu bar tints for light and dark mode

tac.application.tray.closeHidesWindow
  honored: closing the window hides it, and its page keeps running until Quit

tac.application.tray.dock
  honored: false runs the app from the menu bar only, with no Dock icon (LSUIElement)

tac.application.rust
  honored: vendored crates linked into the app's Rust services

tac.application.rust.executables
  honored: signed helper programs in Contents/MacOS

tac.origin

tac.sitemap
  not applicable: tac.sitemap adds entries to sitemap.xml for search engines. The macOS app bundle holds the file, but nothing reads it there.

tac.cache

tac.metadata
  adapted: tac.metadata tags are written into each page, but search-engine and sharing tags do nothing inside the macOS app.

tac.application.permissions

tac.browserApis

tac.browserApis share

tac.browserApis notifications
  run owed: UNUserNotificationCenter through the host bridge (browserApi.notifications), also shown while the app is in front; still to run: the permission prompt and a notification on a Mac, checked by hand

tac.browserApis geolocation
  run owed: CoreLocation through the host bridge (browserApi.geolocation), asking with the reason from tac.application.permissions; still to run: the location prompt with the manifest reason on a Mac, checked by hand

tac.browserApis preferenceStrings
  run owed: the web view's localStorage, kept on disk; still to run: a preferenceStrings write read back after a relaunch on a Mac

tac.nativeCapabilities
  adapted: tac.nativeCapabilities filePicker opens the system file panel on macOS for page, Swift and Rust services. A FilePicker field in a C# or Kotlin service answers unsupported (FP5).

tac.elements
  adapted: tac.elements are bundled into the macOS app for its own pages only. Other sites cannot load them from the app.

tac.python
  run owed: Pyodide in the web view (ADR 0093); still to run: a Python service in the packaged macOS app on a Mac (ADR 0093)

tac.budgets
  not applicable: tac.budgets is checked only by web release builds. The macOS app loads its bundle from disk, so route sizes are not measured (ADR 0074).

tac.outgoing
  honored: the build checks request hosts and the scheme handler's connect-src allows only them

tac.yon
  adapted: tac.yon.origin: the macOS app's pages and linked Swift HTTP clients reach this origin from tachyon-app://bundle, and Yon receives Origin: tachyon-app://bundle; run by scripts/native/yon-reach-test.mjs on macOS 26.6.2 (ADR 0103). A linked Rust service's HTTPClient, and any other async linked Rust member, answers HTTP_MISSING there, because the macOS host does not run Rust tasks yet (LR1).

background and foreground signal
  run owed: ApplicationStateChanged when the app stops or starts being the active app, is hidden or shown, or its window is minimized or restored; still to run: resigning and becoming the active app, hiding and minimizing on a Mac

stored data (IndexedDB, Cache API, LocalState)
  honored: kept on disk by the web view

service worker
  not applicable: The macOS app registers no service worker: its pages load from the app bundle, and the page applies tac.cache rules to Yon reads itself.

Content-Security-Policy
  honored: the native host policy

reaching Yon
  adapted: The macOS app's pages load from tachyon-app://bundle, so same-origin requests reach no Yon. Pages and linked Swift HTTP clients reach the Yon at tac.yon.origin, run on macOS by scripts/native/yon-reach-test.mjs (NET1). A linked Rust service's HTTPClient, and any other async linked Rust member, answers HTTP_MISSING there, because the macOS host does not run Rust tasks yet (LR1).

natively linked service languages
  honored: Rust and Swift services are linked into the app; other languages run in the page

build architecture (--arch)
  honored: --arch x64, arm64 or universal; universal joins an arm64 and an x86_64 build with lipo

release packaging
  run owed: ty bundle --release builds a .dmg whose app is signed with the team's Developer ID certificate and the hardened runtime, then notarizes and staples it; the team and notary profile come from TAC_APPLE_TEAM_ID and TAC_APPLE_NOTARY_PROFILE. Other builds are an ad hoc signed .app; still to run: a notarized Developer ID .dmg; an ad hoc --release run passed on a Mac, and the notarized run waits on the Apple developer agreement (PKG1)

incremental route reuse
  honored: routes are reused from the previous app's web folder; --no-incremental turns this off

byte-identical rebuilds
  run owed: the macOS build passes SOURCE_DATE_EPOCH and ZERO_AR_DATE to swiftc and compiles from the source folder; a --release .dmg differs between builds, because its secure timestamp and notarization ticket change; still to run: a_packaged_macos_app_is_byte_identical_when_built_twice on a Mac (TL2)

running without a signed-in desktop session
  not applicable: The macOS app needs a signed-in graphical session: its window and web view do not start without one, so its gates run on a signed-in Mac.
