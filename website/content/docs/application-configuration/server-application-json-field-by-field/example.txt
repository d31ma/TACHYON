server.host
  The address ty serve and ty start bind; 127.0.0.1 unless set.
  localhost or a name under .localhost (shop.localhost) binds
  127.0.0.1 and prints the name. Anything but loopback also needs
  --allow-non-loopback, and --host overrides it.

server.hosts
  Extra names that a loopback server answers, such as
  ["preview.example.com", "*.tunnel.example"]: names without
  scheme, port or path. Localhost names, IP addresses and the
  tac.origin host always work; other names get 403 (TY1366).

server.port
  The port, 0 to 65535; 8080 unless set. 0 picks a free port, and
  --port overrides it.

datasource.driver
  postgresql, mysql, mariadb, sqlserver, sqlite or fylo.

datasource.url
  Where the database is, without credentials:
  postgresql://db:5432/catalog, sqlite:///var/lib/catalog.db,
  sqlite::memory:, or the absolute root of a FYLO store.

datasource.username
  The database user, usually YON_DATASOURCE_USERNAME in .env beside
  YON_DATASOURCE_PASSWORD, which only .env may hold. SQLite and FYLO
  take neither.

datasource.tls.ca
  Absolute path of a CA certificate to trust.

redis.url
  The Redis server: redis://, or rediss:// for TLS.

redis.username
  The Redis user, usually YON_REDIS_USERNAME in .env beside
  YON_REDIS_PASSWORD, which only .env may hold.

topics.directory
  The folder of the topic logs; data/topics unless set. A plain
  path inside the project or an absolute path with no symbolic
  link. Never inside .tachyon, which holds only generated files.

anything else
  The application's own settings. catalog.page.size is
  yon.catalog.page.size, and YON_CATALOG_PAGE_SIZE names it in
  Settings.

Limits: keys are lowercase letters and digits; at most 128 keys,
16 levels deep and 64 KiB per file. A tac section or a yon root key
stops the build and says where it belongs.
